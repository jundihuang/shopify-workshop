# Inflation Wear T-shirt 样例商品包

来源：合作伙伴 [INFLATION / inflationwear.com](https://inflationwear.com/collections/tshirt) 的 T-shirt 集合公开商品数据（截取约 8 个 SKU，Workshop 用）。

| 文件 | 用途 |
|---|---|
| `products.inflationwear-tshirt.sample.csv` | CSV 样例 |
| `products.inflationwear-tshirt.sample.xlsx` | Excel 样例 |

说明：

- 默认 `status=draft`，导入后不自动发布渠道。
- 图片 URL 指向对方 CDN；现场若图不可访问，可开 Demo 图 Fallback。
- `source_url` 仅供溯源，导入器可忽略未知列。
- 价格/文案以抓取当时公开页为准，仅作 Workshop Demo，不代替对方正式目录。
